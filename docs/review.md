# Review protocol

Start with an explicit version of each language. Examine all heuristic differences, then read each whole description. Pay particular attention to inclusions, exclusions, delivery dates, taxes, availability and legal qualifications that these limited checks cannot fully understand. Resolve ambiguities with the source owner.

Record the real reviewer and export the review bundle. Re-import to continue later. Editing either text or the ID invalidates the recorded review. The current/pending filter reflects that lifecycle, not just whether an approval object exists. The tool provides no electronic signature or access-control mechanism.
